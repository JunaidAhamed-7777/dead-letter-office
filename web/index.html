Local MiniLM semantic search ranks passages from this fictional archive. The results quote the letters and let you inspect every source. They are not generated testimony.

Similarity measures relevance, not truth or the probability that an answer is correct. A close match can still miss your question. Conflicting accounts remain conflicting. Links between those accounts are manually catalogued, not discovered by the model.

The model runs on the local server. This interface sends questions only to that server, does not save them in browser storage, and uses no external fonts, analytics, or hosted AI APIs.
